# Aladdin X2 Plus

A ceiling-mounted projector with an integrated light and speakers. The device identifier used in this repository is **H0002**.

## Hardware

From the [manufacturer's specifications](https://www.aladdinx.jp/pages/aladdin-x2-plus-spec-use):

| Component | Specification |
| --- | --- |
| CPU designation | T950X2 |
| Physical CPU family | ARM; exact core/revision not documented here |
| RAM | 2 GB |
| Storage | 32 GB |
| Projection | Single-chip DLP; 0.33-inch 1080p DMD |
| Brightness | 900 ANSI lumens |
| Light source | LED |
| Speakers | 8 W + 8 W |
| Wi-Fi | 2.4/5 GHz, Wi-Fi 6 (802.11b/g/n/ac/ax) |
| Bluetooth | 5.0 |
| Dimensions | 476 × 145 × 476 mm (W × H × D) |
| Weight | 4.9 kg |
